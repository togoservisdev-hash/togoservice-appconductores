# App de conductores TO GO: APK

Aquí solo se publican los APK de la app de conductores, en
[Releases](https://github.com/togoservisdev-hash/togoservice-appconductores/releases). El código está en el
repositorio `go_to_service_SAC` (`apps/driver`).

A los conductores no se les manda este enlace: se les manda `/descargar-app` del panel, que siempre lleva a la
última versión registrada.

Cada versión es un release con la etiqueta `build-<versionCode>` y el archivo `togo-conductores.apk`. El enlace
directo que se registra en el panel (Configuración → App de conductores) es:

`https://github.com/togoservisdev-hash/togoservice-appconductores/releases/download/build-<versionCode>/togo-conductores.apk`
