# App de conductores TO GO: APK

Aquí solo se guardan los APK de la app de conductores. El código está en el repositorio `go_to_service_SAC`
(`apps/driver`).

A los conductores no se les manda este enlace: se les manda `/descargar-app` del panel, que siempre lleva a la
última versión registrada.

| Versión | Build | Archivo |
|---|---|---|
| 0.2.0 | 10 | [build-10/togo-conductores.apk](build-10/togo-conductores.apk) |

Cada versión va en su carpeta `build-<versionCode>/togo-conductores.apk`. El enlace directo que se registra en el
panel (Configuración → App de conductores) es:

`https://github.com/togoservisdev-hash/togoservice-appconductores/raw/main/build-<versionCode>/togo-conductores.apk`
